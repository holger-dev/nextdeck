# Version 1.8

## DE

### Highlights
- **Modernisiertes UI**: Schwebende Glas-Tab-Bar im iOS-17/18-Stil (rounded corners, Backdrop-Blur), softere Karten-Schatten, durchgängiges Tokens-System (Spacings, Radien, Schatten).
- **Schnellerer Sync**: HTTP-Connection-Pool (Keep-Alive), JSON-Decoding für große Boards/Listen läuft jetzt im Background-Isolate, ~80 → 1 UI-Rebuild pro Sync-Pass durch automatisches Coalescing.
- **Konflikt-Schutz**: Vor jedem Save wird der Server-Stand verglichen — wenn jemand die Karte zwischenzeitlich geändert hat, kommt ein klarer Dialog (Aktuelle laden / Trotzdem überschreiben).
- **iOS-Shortcuts/Siri**: Karten direkt aus Shortcuts oder per Siri anlegen via `nextdeck://newcard?title=…`.
- **Server-Benachrichtigungen**: Die App pollt jetzt zusätzlich die zentrale Nextcloud-Notifications-API. Damit kommen Banner für **Karten-Zuweisungen, @-Erwähnungen in Kommentaren und Shares** — auch in nicht-aktiven Boards. Voraussetzung: `notifications`-App auf dem Server.

### Bugfixes
- #50 / #68: Links in Karten-Beschreibung sowie URLs in Kommentaren sind jetzt klickbar (öffnen extern).
- #51: Board-Farben in der Übersicht sind nicht mehr zu dunkel — pastelliger Light-Mode, klar erkennbarer Dark-Mode.
- #58: Karten-Reihenfolge bleibt stabil, auch wenn parallel Karten im Browser geöffnet werden.
- #61: MP3- und andere Audio-Anhänge öffnen sich zuverlässig im iOS-Player.
- #62: Boards können jetzt gelöscht werden — destruktive Aktion klar markiert, Caches werden mit aufgeräumt.
- #63: Listen-Titel sind editierbar (Board-Menü → „Liste umbenennen").
- #65: Status-Chips überlappen die Karten in der Tablet-Übersicht nicht mehr.
- #67: Datei-Anhänge laden gegen aktuelle Nextcloud-Versionen wieder hoch (OCS-APIRequest-Header, mehrere Endpoint-Varianten, ausführliches Debug-Log).

### Verbesserungen
- #53: Markdown-Toolbar zwei-reihig — Bullet, Numbered List, Task-List und Quote sind sofort sichtbar; Placeholder-Text wird automatisch markiert, beim Tippen direkt überschrieben.
- #54: Pro-Board-Sync-Intervalle: pro Board einstellbar (1/5/15/30 min), globaler Default bleibt erhalten.
- #55: Lokale Push-Benachrichtigungen für neue Zuweisungen und @-Erwähnungen — kein Doppel-Ping bei wiederholten Syncs.
- #56: Karten via URL-Schema oder iOS-Shortcut anlegen (`nextdeck://newcard?title=…&board=…&stack=…`).
- #59: Optimistic-Concurrency-Detection: Server-`lastModified` wird vor jedem Save geprüft.
- #66: Info-Chips in der Board-Übersicht lassen sich global ausblenden.
- Beschreibung scrollt intern, wenn sie länger wird — Anhänge und Kommentare bleiben ohne langes Scrollen erreichbar.
- Skeleton-Loader statt Activity-Spinner beim ersten Laden eines Boards.
- Haptik beim Drag-Drop und Tab-Wechsel.

## EN

### Highlights
- **Modernized UI**: Floating glass tab bar in iOS 17/18 style (rounded corners, backdrop blur), softer card shadows, app-wide design tokens (spacings, radii, shadows).
- **Faster sync**: HTTP connection pooling (keep-alive), JSON decoding for large boards/lists offloaded to a background isolate, ~80 → 1 UI rebuilds per sync pass through automatic coalescing.
- **Conflict protection**: Before each save the server state is compared — if someone modified the card in the meantime, a clear dialog appears (Reload current / Overwrite anyway).
- **iOS Shortcuts / Siri**: Create cards directly from Shortcuts or via Siri using `nextdeck://newcard?title=…`.
- **Server notifications**: The app now also polls the central Nextcloud notifications API. Banners now arrive for **card assignments, @-mentions in comments and shares** — even in non-active boards. Requires the `notifications` app on the server.

### Bug fixes
- #50 / #68: Links in card descriptions and URLs in comments are clickable now (open externally).
- #51: Board colors in the overview are no longer too dark — softer light mode, clearer dark mode.
- #58: Card order stays stable even when cards are opened in parallel in the web browser.
- #61: MP3 and other audio attachments reliably open in the iOS player.
- #62: Boards can now be deleted — destructive action clearly marked, caches cleaned up.
- #63: List titles can be edited (board menu → "Rename list").
- #65: Status chips no longer overlap cards in the tablet overview.
- #67: File attachments upload again on current Nextcloud versions (OCS-APIRequest header, multiple endpoint variants, detailed debug log).

### Improvements
- #53: Two-row markdown toolbar — bullet, numbered list, task list, and quote always visible; placeholder text is auto-selected so you can type right over it.
- #54: Per-board sync intervals: configurable per board (1/5/15/30 min), global default preserved.
- #55: Local push notifications for new assignments and @-mentions — no duplicate pings on repeated syncs.
- #56: Create cards via URL scheme or iOS Shortcut (`nextdeck://newcard?title=…&board=…&stack=…`).
- #59: Optimistic-concurrency detection: server `lastModified` is checked before every save.
- #66: Info chips in the board overview can be hidden globally.
- Long descriptions scroll inline — attachments and comments remain reachable without endless scrolling.
- Skeleton loaders instead of activity spinners when a board first loads.
- Haptic feedback on drag-drop and tab switching.

## ES

### Destacado
- **UI modernizada**: Barra de pestañas flotante estilo iOS 17/18 (esquinas redondeadas, blur), sombras suaves en tarjetas, tokens de diseño consistentes (espaciados, radios, sombras).
- **Sincronización más rápida**: Reutilización de conexiones HTTP (keep-alive), decodificación JSON de tableros/listas grandes en isolate de fondo, ~80 → 1 reconstrucciones de UI por sincronización gracias a coalescing.
- **Protección de conflictos**: Antes de cada guardado se compara el estado del servidor — si alguien modificó la tarjeta en paralelo, aparece un diálogo claro (Cargar actual / Sobrescribir de todos modos).
- **Atajos iOS / Siri**: Crear tarjetas desde la app Atajos o por Siri con `nextdeck://newcard?title=…`.
- **Notificaciones del servidor**: La app consulta ahora la API central de notificaciones de Nextcloud. Llegan banners para **asignaciones, @-menciones en comentarios y compartidos**, incluso en tableros no activos. Requiere la app `notifications` en el servidor.

### Correcciones
- #50 / #68: Enlaces en descripciones y URLs en comentarios ahora se pueden tocar.
- #51: Colores de tableros en el resumen ya no son demasiado oscuros.
- #58: El orden de tarjetas se mantiene estable, incluso si se abren tarjetas en paralelo en el navegador.
- #61: Adjuntos MP3 y otros audios se abren de forma fiable en el reproductor iOS.
- #62: Los tableros se pueden eliminar.
- #63: Los títulos de las listas son editables.
- #65: Los chips de estado no se superponen con las tarjetas en la vista de tablet.
- #67: Los adjuntos de archivos se suben de nuevo en versiones actuales de Nextcloud.

### Mejoras
- #53: Barra de herramientas de Markdown en dos filas con auto-selección del placeholder.
- #54: Intervalos de sincronización por tablero.
- #55: Notificaciones locales para asignaciones y menciones.
- #56: Crear tarjetas vía esquema de URL o Atajo iOS.
- #59: Detección de concurrencia optimista.
- #66: Chips informativos en el resumen ocultables.
- Descripción larga con scroll interno.
- Skeleton-loaders durante la primera carga.
- Feedback háptico al arrastrar y cambiar pestañas.
